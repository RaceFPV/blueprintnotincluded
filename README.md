# Blueprintnotincluded

This is the source repo of blueprintnotincluded.org

It is a combined curated version of the original blueprintnotincluded web app.

## Easy local testing w/ docker-compose

`docker compose up --build`

Visit http://localhost:3000
To check incoming emails visit: http://localhost:8025

## Docker image building

Build the image

`docker build . -t bpni:latest`

Run mongodb (mongoose version only allows mongo version 4.2)

`docker run -d -p 27017:27017 mongo:4.2`

Run the image and backend

`docker run -d -p 3000:3000 -e JWT_SECRET=mysecretkey -e ENV_NAME=development -e CAPTCHA_SITE=localhost -e CAPTCHA_SECRET=mysecretkey -e DB_URI="mongodb://127.0.0.1:27017/blueprintnotincluded" bpni:latest`

Visit http://localhost:3000

Export images from oniextract2020

## Automated Asset Pipeline (Recommended)

### Prerequisites
- **OniExtract2020 mod**: Updated version with fixed sprite extraction (see conversation history for required fixes)
- **Oxygen Not Included game**: With the mod installed and working

### Required Input
The automated pipeline requires an `export.zip` file generated by the OniExtract2020 mod, containing:
- `export/database/database.json` - Game database with all building/element data
- `export/images/` - Extracted texture files from the game

### Usage Instructions

1. **Generate Game Data**
   ```bash
   # Run Oxygen Not Included with the OniExtract2020 mod installed
   # The mod should generate an export.zip file in your game directory
   ```

2. **Copy Export File**
   ```bash
   # Copy the export.zip file to your blueprintnotincluded project root
   cp /path/to/your/game/export.zip ./export.zip
   ```

3. **Run Complete Pipeline**
   ```bash
   # Single command to process everything
   npm run extract
   
   # OR if you want to clean everything first
   npm run extract:clean
   ```


### What the Pipeline Does
The `npm run extract` command automatically:
- ✅ Extracts `export.zip` and validates contents
- ✅ Sets up directory structure and copies database  
- ✅ Moves all texture images to correct locations
- ✅ Processes database (fixes HTML labels, adds info icons, applies renames)
- ✅ Generates element UI sprites (individual material/element icons)
- ✅ Generates category icons (build menu categories)
- ✅ Generates building group sprites (composite building images)
- ✅ Copies final processed assets to frontend
- ✅ Prepares everything for the web application

### Troubleshooting
- **"export.zip not found"**: Ensure the file is in the project root directory
- **Memory errors**: The pipeline uses `--max_old_space_size=4096` for large image processing
- **Missing textures**: Verify your OniExtract2020 mod extracted images correctly
- **Debug mode**: Use `npm run extract:debug` to run with debugger attached

This replaces the manual "Image reconstruction" process above with a single automated command.
